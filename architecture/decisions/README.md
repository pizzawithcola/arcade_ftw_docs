# 架构决策记录（ADR）

## 约定

- 一个决策一个文件：`NNNN-短标题.md`（如 `0001-polyrepo.md`）。
- 每个文件含：`状态`（proposed / accepted / superseded）、`背景`、`决策`、`理由`、`后果`。
- **已被采纳的决策不要推翻重来**，除非用户明确要求；要改就新写一条 `supersedes` 它。
