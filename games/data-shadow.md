# Data Shadow

主流程第 4 个节点（`type: game`，`game: data_shadow`）。
代码：`arcade_ftw_fe/src/games/dataShadow/`。

## 玩法

屏幕上是**一条 LinkedIn 风格的帖子**，作者是某公司的 Head of Customer Experience。
帖子读起来完全正常、积极、专业——但里面泄露了**不该公开的信息**。

玩家点选任何「不该出现在 LinkedIn 上」的片段，然后 Submit。

| 结果 | 得分 |
|---|---|
| 点中真正的泄露 | **+10** |
| 点了一个其实没问题的片段（误报） | **−10** |
| 放过了一个泄露 | 0 |
| 放过一个安全片段 | 0 |

满分 **90**（9 个泄露 × 10）。整轮 **45 秒**，到点自动提交。

## 为什么是「可点击片段」而不是任意拖选

大屏/触屏上用鼠标**拖选任意文本**：操作难、误选多、而且**无法精确判分**（玩家选中的字符串和标准答案不会逐字一致）。所以帖子在数据层就被**预先切成最小判断单元**，每段一个可点击的 inline 元素。

**关键：安全片段也可点击。** 如果只有泄露项能点，答案就退化成「把所有亮起来的东西都点一遍」。所以帖子里**故意放了诱饵**——玩家必须真的判断。

## 为什么误报要扣分（这条是设计核心）

误报不是无害的：它正是那种「见什么怀疑什么」的条件反射，会让人把普通句子也举报，反而漏掉真正要命的。所以：

| 策略 | 得分 |
|---|---|
| 完美（只点 9 个泄露） | **90** |
| **全部点选（刷分）** | **20** |
| 全部不点 | 0 |

「全部点选」只有 20 分（满分 90）——**刷分策略不可行**。这条有专门的断言守着。

## 9 个泄露与教学点

| 片段 | 为什么是泄露 |
|---|---|
| `19 markets` | 精确运营覆盖范围 = 竞争情报 |
| `2.4 million interactions/month` | 内部业务量，暴露规模与成本结构 |
| `37% reduction in handling time` | 「internal results」就是提示词——未公开的效能指标 |
| `12% satisfaction increase` | 第二个未公开内部指标 |
| `launch across Asia in November` | 未宣布的路线图 + 日期 + 区域 = 可能影响市场 |
| `full regional deployment by Q2` | 前瞻性时间表，等于公开承诺 |
| `Sarah Chen` | 公开点名同事并把她与未发布项目绑定 |
| `Project Nova` | 内部代号：对观众无意义，对钓鱼/社工的人正好是关键词 |
| `real customer conversation data` | **最严重**：公开承认用真实客户对话训练，且未提同意与法律依据 = 隐私与合规风险 |

**7 个诱饵**（可点击但安全）：开场白、泛泛的能力描述、「preparing for the next phase」、hashtags 等。

> 💡 设计意图：真正危险的那条（客户数据）藏在**读起来最像「我们很创新」**的句子里。这就是「data shadow」的含义——泄露往往不像泄露。

## 揭晓

提交后**帖子本身变成讲解**（而非另开一页）：

- 🟩 绿底 = 点中的泄露
- 🟧 橙底 = 漏掉的泄露
- 🟥 红底删除线 = 误报

下方再给**漏掉的每一条 + 原因**。「漏掉」是重点教学内容，所以单独列出、逐条解释原因。

## ⚠️ 版面约束（大屏）

帖子本身约 **900px** 高，1080p 屏幕上已经占满。所以：

- **分数放在顶栏**，永远可见，不受下方内容影响。
- 漏掉的清单**限高可滚动**（`max-height: 17rem`），否则整页会被撑到 1350px+ 而需要滚动。

> ⚠️ 如果以后往帖子里加段落，**先确认帖子高度仍在 1080p 内**，否则玩家会在 kiosk 上看不到 Submit 按钮。

## 当前状态与限制

- **纯前端、硬编码**（`content.ts`）：1 条帖子、9 个泄露。
- **分数不落库**，刷新即清零。
- **只有一轮**：`ROUND_SECONDS = 45`，整条帖子一个总倒计时（不像 quiz 是每题一个）。
- 节点时长 **51 秒**（45 + 6 秒收尾）。改 `ROUND_SECONDS` 时**必须同步改 `flow.py`**——手工保持一致，没有代码校验。
